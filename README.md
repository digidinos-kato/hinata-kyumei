# hinata-kyumei

救急救命士の学習ドリル（ブラウザで開くだけで動く静的サイト）。

## 入口

トップ画面で次の2つから選ぶ。

| 入口 | 内容 | データ |
| --- | --- | --- |
| 救急救命士 完全対策問題集 | 章ごとの基礎問題＋模擬試験（500問） | `index.html` 内の `DATA` |
| 国試本試験（過去問） | 救急救命士国家試験の過去問を年度（回）別に収録 | `data/kokushi/<回>.js` |

## 国試本試験の収録状況

| 回 | 年度 | 実施日 | 収録数 |
| --- | --- | --- | --- |
| 第48回 | 令和6年度 | 2025年3月9日 | 117問 |
| 第47回 | 令和5年度 | 2024年3月10日 | 115問 |
| 第46回 | 令和4年度 | 2023年3月12日 | 118問 |
| 第45回 | 令和3年度 | 2022年3月13日 | 118問 |
| 第44回 | 令和2年度 | 2021年3月14日 | 114問 |

- いずれも A 問題（一般問題）。分野別過去問題集の写真から書き起こしたもので、各回の全問ではない。
- 解説は独自に書いた要約。
- 図が必要な問題の図は `data/kokushi/fig/<回>-<区分>-<番号>.jpg`。
- 書籍で「3又は4」のように複数正解扱いの問題は `anyOf: true`（どれか1つを選べば正解）。

## 年度を追加するには

`data/kokushi/<回>.js` を作り、`index.html` の `<!--KOKUSHI_SCRIPTS-->` 内に `<script src="data/kokushi/<回>.js"></script>` を追加する。

```js
(window.KOKUSHI_EXAMS = window.KOKUSHI_EXAMS || []).push({
  round: 49, nendo: '令和7年度', date: '2026年3月8日',
  questions: [
    { id: 'k49-A-1', n: 'A-1', q: '問題文', choices: ['...', '...'], answer: [2], exp: '解説', topic: '分野', fig: 'data/kokushi/fig/49-A-1.jpg' }
  ]
});
```

`answer` は 0 始まりの配列（「2つ選べ」は2要素）。
